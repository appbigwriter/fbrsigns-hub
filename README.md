# FBR Signs Admin Dashboard

This is the admin dashboard for FBR Signs, built with React, Vite, and Supabase.

## Project Info

This project is designed to manage orders, products, and customers for FBR Signs.

## Getting Started

To run this project locally:

1. **Prerequisites**: Ensure you have Node.js installed.
2. **Clone the repository**:
   ```sh
   git clone <YOUR_GIT_URL>
   cd fbrsigns-admin
   ```
3. **Install dependencies**:
   ```sh
   npm install
   ```
4. **Start the development server**:
   ```sh
   npm run dev
   ```

## Technologies Used

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase

## Deployment

This project can be deployed to any static hosting service like Vercel, Netlify, or similar.
